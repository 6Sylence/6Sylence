## Pipeline usado (documentado para futuros runs)
1. Diseños generados con `store-assets/nube_salpicadura.py` (PIL, seamless para calzado).
2. Subida a CDN Shopify: `stagedUploadsCreate` → POST multipart → `fileCreate`.
3. Mockups: Printful Mockup Generator (`POST /mockup-generator/create-task/{product_id}`,
   requiere campo `position` calculado desde `/mockup-generator/printfiles/{id}`).
4. Producto en Shopify (MCP create-product, ACTIVE, type/tags para colecciones smart).
5. Espera al auto-import de Printful y vinculación: `PUT /sync/variant/{sync_variant_id}`
   con `{variant_id, retail_price, files[{type,url}]}` (script `link_printful.py` en
   scratchpad; los sync products importados llegan con is_ignored=true hasta vincular).
6. Verificación: `GET /sync/products/{id}` → synced == variants.
