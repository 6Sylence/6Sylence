## Pipeline Printful confirmado (importante para futuros runs)
`POST /store/products` NO funciona para tiendas tipo Shopify (400) y
`PUT /sync/products/{id}` devuelve 405. El flujo que sí funciona (y el que usaron
los drops anteriores):
1. Generar diseños con PIL (2x supersampling + LANCZOS) → `store-assets/designs/`.
2. Subir prints a Shopify Files vía `stagedUploadsCreate` + POST multipart + `fileCreate`.
3. Crear el producto en Shopify vía MCP `create-product` (título, Talla, SKUs, precios,
   descripción ES, tags, tipo, ACTIVE). Printful lo importa automáticamente en segundos
   como sync product (buscable por `GET /sync/products/@{shopify_id}?store_id=...`).
4. Configurar variante a variante: `PUT /sync/variant/{sync_variant_id}` con
   `variant_id` (catálogo), `retail_price`, `is_ignored: false` y `files`.
   Rate limit ~120/min: pausar 1-3 s entre PUTs y reintentar 429 con espera 35 s.
5. Printful genera mockups y los sube como imágenes del producto en Shopify (~min).
