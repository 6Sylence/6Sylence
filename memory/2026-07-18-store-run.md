## Flujo técnico (el "como siempre" documentado)
1. Diseños PIL → PNG (tee 2400×3000, hoodie 2250×2250, sweat 2400×3000,
   altas 2400×2400, deportivas 2000×3400, calcetines 2000×2000).
2. `stagedUploadsCreate` + `fileCreate` → URLs cdn.shopify.com (neon_*.png).
3. Mockups vía Printful `/mockup-generator/create-task/{product_id}` con las URLs del CDN.
4. `create-product` en Shopify (ACTIVE, vendor SRHOOD, opción "Talla", tags de
   convención: color + novedades + SRHOOD + streetwear + género + tag de cápsula).
5. Esperar import automático de Printful (~1 min) y `PUT /sync/variant/@{shopify_variant_id}`
   con `variant_id` de catálogo + `retail_price` + `files`.
   ⚠️ Rate limit Printful: ~10 PUTs seguidos → 429 de 60 s. Usar pausa de ~2 s
   por PUT y backoff de 65 s en 429.
