## Concepto del drop
Carta estelar astronómica REAL de la constelación Corona Borealis (la "Corona del
Norte"): planisferio con anillo graduado, retícula RA/Dec, posiciones J2000 y
magnitudes auténticas de las 7 estrellas (θ–β–α–γ–δ–ε–ι, Alphecca como joya),
guiño a la variable R CrB. Oro + marfil sobre negro/azul medianoche.
Generador: `store-assets/corona_boreal.py` (PIL + fuentes OFL Cinzel/Cormorant,
texto circular glifo a glifo, supersampling 2×).

## Workflow técnico (el que funciona)
1. Diseños PIL a dimensiones EXACTAS de printfile Printful.
2. Subida a Shopify Files: stagedUploadsCreate → POST GCS → fileCreate → URL CDN.
3. Printful Mockup Generator API (v1, X-PF-Store-Id 18383330):
   POST /mockup-generator/create-task/{product_id} — REQUIERE `position` en cada
   file ({area_width, area_height, width, height, top:0, left:0}).
   OJO: /store/products v1 NO sirve para tiendas tipo shopify (solo mockups).
4. create-product MCP con URLs de mockups Printful (Shopify los rehospeda).
5. inventorySetQuantities (available, ignoreCompareQuantity) → 9999/variante.
   Location: gid://shopify/Location/116855341440.
