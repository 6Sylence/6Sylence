## Pipeline Printful↔Shopify (documentado y verificado en este run)
1. Generar diseño con PIL (garments 3600×4800 front; zapatillas lona/altas 2325×2325;
   calcetines 1400×2400; athletic 3900×6600; flip-flops 3300×3900).
2. Subir PNG a Shopify Files: `stagedUploadsCreate` (httpMethod PUT es lo más simple)
   → curl PUT → `fileCreate` → poll `nodes` hasta READY → URL cdn.shopify.com.
3. Mockups: POST `/mockup-generator/create-task/{catalog_product_id}`
   (variant_ids=[1 representativo], files con placement + **position obligatorio**)
   → poll `/mockup-generator/task?task_key=`.
4. Crear producto en Shopify (MCP create-product) con mockups como imágenes,
   variantes/SKU/precio/tags/tipo. Shopify copia las imágenes a su CDN.
5. Printful importa el producto solo (~1 min) → buscar id con `/sync/products?search=`.
6. Vincular cada variante: **PUT `/sync/variant/{sync_variant_id}`** (¡SINGULAR!
   `/sync/variants/{id}` NO existe y devuelve el error engañoso "Missing required
   parameters: external_ids") con body `{variant_id, files[{type,url,position}],
   is_ignored:false}`. Rate limit ~10 PUT/min → backoff con el mensaje del 429.
