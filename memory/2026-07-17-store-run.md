Tienda: Street Royalty Hood (srhood.com) · Shopify + Printful (store id 18383330) · EUR

## Flujo confirmado "como siempre" (documentado para futuros runs)
1. Diseño PNG con PIL (prendas 3600×4800 transparente; zapatillas lona 2325×2325
   opaco; calcetines 1400×2400). Supersampling 2x + LANCZOS.
2. Subida a Shopify Files: `stagedUploadsCreate` (MCP graphql) → POST multipart a
   Google Storage → `fileCreate` → URL cdn.shopify.com.
3. Mockups: Printful `POST /mockup-generator/create-task/{product_id}` con
   `variant_ids`, `files[{placement, image_url, position}]` (position obligatorio).
   Placements calzado moderno (578 lace-up, 525/513 high-top): `shoe_quarters_left/right`
   + `shoe_tongue_left/right`; slip-on 574 y slides 597/598: `shoe_left/right`.
   Rate limit ~4 tareas/min (429 → esperar 60 s).
4. Crear producto Shopify (MCP create-product) en DRAFT con mockups como imágenes,
   opción "Talla", SKUs SRH-XXnn-Talla.
5. Printful importa solo (~1 min). Los DRAFT entran como `is_ignored: true`, pero
   `PUT /sync/variant/{id}` con `{variant_id, files:[{type,url}]}` funciona igual y
   al sincronizar todas las variantes el producto deja de estar ignorado.
6. Activar productos (bulk-update-product-status) SOLO tras sync completo.
