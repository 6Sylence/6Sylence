## Hallazgo clave
Los productos de los runs recientes se creaban SOLO en Shopify: en Printful aparecían
importados pero con **0 variantes sincronizadas** (sin variant_id de catálogo ni print
files), es decir, Printful no podría fabricarlos. Estado al inicio del run: 1.064 sync
products, solo 399 con variantes sincronizadas (los antiguos creados desde el dashboard).

Este run estrena el flujo completo por API (el bueno):
1. Diseño generado con PIL (`store-assets/street_lab.py`) a resolución de print file.
2. Subida del print file al CDN de Shopify (stagedUploadsCreate + fileCreate).
3. Mockups REALES con el Mockup Generator de Printful (antes se simulaban con PIL).
4. Producto en Shopify (create-product, ACTIVE) con esos mockups.
5. Espera a la importación automática en Printful y **PUT /sync/variant/{id}** con
   variant_id de catálogo + files → variantes `synced: true`, fulfillment operativo.
   OJO: el endpoint es **singular** (`/sync/variant/`); `/sync/variants/` devuelve el
   error engañoso "Missing required parameters: external_ids". Rate limit agresivo:
   espaciar PUTs ~1,5 s y reintentar tras 429.
