## Observado
- **srhood.com responde HTTP 402 "Tienda no disponible"**: la tienda está pausada o
  bloqueada por facturación. Ningún visitante puede ver ni comprar nada.
- La Admin API (MCP de Shopify) rechaza todas las llamadas con `operation_not_allowed`
  ("shop is unavailable for API access... billing issue or upgrade their plan").
- Consecuencia: este run no pudo auditar ventas, sesiones ni catálogo, ni publicar nada.
  Sin cambios en la tienda.

## Aprendido
- Antes de cualquier run, comprobar primero `get-shop-info` y `curl -I https://srhood.com`.
  Un 402 significa facturación/plan, no un fallo técnico: solo lo resuelve el titular en
  https://admin.shopify.com/store/r1gygn-u2/access_account
